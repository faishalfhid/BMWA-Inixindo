# Kunci jawaban lab 3: implementasi EJS

Salin kode dari berkas berikut ke proyek latihan Anda sesuai lokasi tujuan.

| Berkas jawaban | Tempat menempelkan kode | Isi |
| --- | --- | --- |
| [app.js](app.js) | `app.js` | Konfigurasi EJS dan rute pengiriman nama. |
| [views/index.ejs](views/index.ejs) | `views/index.ejs` | Sapaan dari variabel namaPengguna. |

## Cara menggunakan

Lanjutkan proyek latihan Lab 2. Setelah memasang EJS sesuai petunjuk lab, ganti seluruh isi `app.js`, lalu buat atau ganti isi `views/index.ejs` menggunakan kode di folder ini.

Jalankan ulang server. Halaman `/` menampilkan `Selamat Datang, Peserta Pelatihan!` dan paragraf `Ini adalah aplikasi pertama menggunakan EJS.` Penulisan `namaPengguna` pada server dan EJS harus sama.
