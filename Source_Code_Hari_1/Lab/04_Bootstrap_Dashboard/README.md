## Cara menggunakan

Lanjutkan proyek latihan Lab 3. Perubahan utama hanya pada `views/index.ejs`; ganti seluruh isinya dengan kode jawaban ini. `app.js` disertakan agar peserta dapat mencocokkan kode server.

Halaman `/` menampilkan kartu `Dashboard Sederhana` dengan sapaan `Halo, Peserta Pelatihan`. Tombol Mulai Belajar masih memiliki `href="#"` sesuai tahap Lab 4. Internet diperlukan untuk memuat Bootstrap dari CDN.
