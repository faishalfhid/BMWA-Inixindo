# Kunci jawaban lab 2: setup proyek Express

Salin kode dari berkas berikut ke proyek latihan Anda sesuai lokasi tujuan.

| Berkas jawaban | Tempat menempelkan kode | Isi |
| --- | --- | --- |
| [app.js](app.js) | `app.js` | Kode server Express lengkap pada akhir Lab 2. |

## Cara menggunakan

Setelah mengikuti langkah penyiapan proyek dan pemasangan Express pada Lab 2, ganti seluruh isi `app.js` dengan kode jawaban ini. Jalankan `node app.js` dari folder proyek latihan.

Buka `http://localhost:3000`. Hasilnya `Hello World! Server Express sudah berjalan.` Gunakan proyek latihan yang sama untuk melanjutkan Lab 3.
