# Kunci jawaban lab 1: eksplorasi Node.js

Salin kode dari berkas berikut ke proyek latihan Anda sesuai lokasi tujuan.

| Berkas jawaban | Tempat menempelkan kode | Isi |
| --- | --- | --- |
| [jawaban.js](jawaban.js) | `jawaban.js` | Pesan Node.js dan perkalian. |
| [repl.txt](repl.txt) | REPL Node.js pada terminal | Baris yang diketik untuk praktik interaktif. |

## Cara menggunakan

Pada latihan REPL, ketik `node`, lalu salin baris JavaScript dari `repl.txt` satu per satu. Alternatifnya, salin isi `jawaban.js` ke berkas di komputer Anda dan jalankan `node jawaban.js`.

Hasil yang dicari:

```text
Halo dari Server Node.js!
Hasil perkalian: 50
```

REPL dapat menampilkan `undefined` setelah `console.log`; itu wajar. Keluar dengan Ctrl+C dua kali atau `.exit`.
