# Peta materi dan lab hari 1

Kode jawaban mengacu pada lima materi dan lima lab dalam folder `Hari_1`, presentasi HTML, serta teks panduan lab Word. Kode diatur per sesi agar peserta dapat menyalin berkas yang sesuai dengan tahap latihan.

| Sesi | Cakupan kode materi | Batas jawaban lab |
| --- | --- | --- |
| 1 | Pesan Node.js, perkalian, simulasi sinkron/asinkron, dan server Express | REPL atau berkas JavaScript dengan pesan dan hasil 50 |
| 2 | Server Express pertama | Respons Hello World sesuai lab |
| 3 | Variabel, if/else, loop, komponen navbar/footer, dan respons teks | Satu halaman dengan variabel namaPengguna |
| 4 | Card, form, tabel, modal, dan grid sidebar/konten | Card dasbor sesuai struktur lab |
| 5 | Tabel karyawan melalui GET serta contoh form POST | Tabel tiga karyawan; array lima karyawan disediakan untuk tantangan |

`app.js` disediakan sebagai kode lengkap untuk mengganti isi berkas pada proyek latihan peserta. Berkas EJS mengikuti lokasi tujuan `views/`. Folder jawaban tidak menyediakan manifest npm, dependensi terpasang, atau skrip menjalankan proyek.

Data wajib Lab 5 tetap Budi Santoso (IT), Siti Aminah (Finance), dan Agus Setiawan (Marketing). Dua data tambahan pada berkas tantangan merupakan contoh untuk latihan menambah baris.

Contoh POST pada Materi 5 hanya menerima nama dan menampilkan sapaan; belum menyimpan data. Penggunaan POST tidak otomatis mengenkripsi isian. Penjelasan mengenai HTTPS tetap diperlukan saat membahas pengiriman data rahasia.
