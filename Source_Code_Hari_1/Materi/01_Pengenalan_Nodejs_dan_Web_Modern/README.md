# Materi 1: pengenalan Node.js dan web modern

Salin kode dari berkas berikut ke proyek latihan Anda sesuai lokasi tujuan.

| Berkas jawaban | Tempat menempelkan kode | Isi |
| --- | --- | --- |
| [hello.js](hello.js) | `hello.js` | Pesan Node.js dan hasil perkalian 50. |
| [synchronous.js](synchronous.js) | `synchronous.js` | Simulasi menunggu A selesai sebelum menjalankan B. |
| [asynchronous.js](asynchronous.js) | `asynchronous.js` | Simulasi menjalankan B saat A menunggu. |
| [app.js](app.js) | `app.js` | Contoh server Express dan respons JSON. |

## Cara menggunakan

Untuk contoh terminal, salin kode ke berkas dengan nama yang sama pada komputer Anda, lalu jalankan dengan `node nama-berkas.js`. Untuk contoh server, ganti seluruh isi `app.js` pada proyek latihan Anda. Buka `/` untuk respons teks atau `/api/pesan` untuk respons JSON.

Jeda 300 milidetik pada contoh sinkron dan asinkron hanya simulasi. Keduanya memakai Node.js; contoh ini tidak mengukur perbandingan kinerja Node.js dengan PHP.
