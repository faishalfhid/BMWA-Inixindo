# Materi 2: persiapan lingkungan kerja

Salin kode dari berkas berikut ke proyek latihan Anda sesuai lokasi tujuan.

| Berkas jawaban | Tempat menempelkan kode | Isi |
| --- | --- | --- |
| [app.js](app.js) | `app.js` | Server pertama dengan respons Hello World. |

## Cara menggunakan

Setelah menyiapkan proyek latihan dan memasang Express sesuai materi, ganti seluruh isi `app.js` dengan kode pada folder ini. Jalankan server dari folder proyek latihan menggunakan `node app.js`.

Buka `http://localhost:3000`. Hasilnya `Hello World! Server Express sudah berjalan.` Folder ini hanya menyediakan kode jawaban; konfigurasi proyek dibuat peserta mengikuti langkah materi.
