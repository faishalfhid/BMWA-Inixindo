# Materi 3: templating dengan EJS

Salin kode dari berkas berikut ke proyek latihan Anda sesuai lokasi tujuan.

| Berkas jawaban | Tempat menempelkan kode | Isi |
| --- | --- | --- |
| [app.js](app.js) | `app.js` | Konfigurasi EJS dan pengiriman data ke tampilan. |
| [views/index.ejs](views/index.ejs) | `views/index.ejs` | Variabel, percabangan, pengulangan, dan include. |
| [views/partials/navbar.ejs](views/partials/navbar.ejs) | `views/partials/navbar.ejs` | Komponen navigasi. |
| [views/partials/footer.ejs](views/partials/footer.ejs) | `views/partials/footer.ejs` | Komponen footer. |

## Cara menggunakan

Ganti seluruh isi berkas tujuan dengan kode pada berkas pasangannya. Pastikan EJS sudah dipasang pada proyek latihan. Jalankan `node app.js` dari folder proyek latihan.

Buka `/` untuk hasil lengkap, `/?status=tamu` untuk cabang tamu, `/?daftar=kosong` untuk daftar kosong, dan `/teks` untuk membandingkan `res.send()` dengan `res.render()`. Status masuk hanya contoh data untuk percabangan.

Lab 3 menggunakan contoh yang lebih sederhana; demo komponen ini membantu pengajar menjelaskan isi materi.
