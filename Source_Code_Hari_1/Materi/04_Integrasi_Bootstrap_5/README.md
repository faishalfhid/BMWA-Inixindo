# Materi 4: integrasi Bootstrap 5

Salin kode dari berkas berikut ke proyek latihan Anda sesuai lokasi tujuan.

| Berkas jawaban | Tempat menempelkan kode | Isi |
| --- | --- | --- |
| [app.js](app.js) | `app.js` | Rute beranda dan sapaan dari isian form GET. |
| [views/index.ejs](views/index.ejs) | `views/index.ejs` | Card, form, tabel, modal, dan grid sidebar/konten. |

## Cara menggunakan

Salin kode ke dua berkas tujuan pada proyek latihan yang sudah memakai Express dan EJS. Buka `/`, isi nama, lalu klik Tampilkan nama. Klik Buka modal dan Tutup untuk mencoba dialog.

Bootstrap 5.3.0 memakai CDN sesuai materi. Internet diperlukan untuk memuat CSS dan JavaScript bundle. Form hanya mengubah sapaan melalui GET dan tidak menyimpan data.
